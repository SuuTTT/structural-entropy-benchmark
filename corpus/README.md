# Structural-entropy survey corpus (84 papers)

This is the tagged corpus behind the survey *Structural Entropy: A Decade Survey of Theory, Algorithms, Learning Paradigms, and Applications*. Every coverage statistic, table and figure in the survey is computed over these 84 papers. The survey cites individually only the papers it discusses; this page gives the full reference and facet tags of every corpus paper.

Files: [`corpus.bib`](corpus.bib) (BibTeX for all 84 papers) and [`corpus.csv`](corpus.csv) (one row per paper with its facet tags).

## Facet codes

**Task:** Th = theory, CD = community detection, HC = hierarchical clustering, GP = graph pooling, SL = structure learning, CS = contrastive self-supervision, RL = reinforcement-learning abstraction, App = application.
**Graph:** S = simple, W = weighted, D = directed, B = bipartite, A = attributed, He = heterogeneous, Hy = hypergraph, Dy = dynamic.
**Repr.:** 1D, 2D, kD = encoding tree of depth k, co = continuous.
**Optim.:** Gr = greedy agglomerative, HM = hierarchical merge, DP = dynamic programming, Sp = spectral, Df = differentiable, Ga = game / local move, In = incremental, Ot = other.
**Role:** Obj = objective, Pri = prior, Met = metric, Reg = regularizer, Fea = feature, Rob = robustness.
**Sup.:** U = unsupervised, S = supervised, SS = self-supervised, Se = semi-supervised.
**Output:** Part = partition, Tree = tree, Sc = score, PG = pooled graph, Em = embedding, Rew = rewired graph, Pol = policy.
"--" = no value; multi-valued cells are comma-separated.
